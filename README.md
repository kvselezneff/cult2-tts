# Cult2 — материалы для Tabletop Simulator

Публичные картинки сценария TTS настольной игры Cult2 (Константин Селезнёв). Сейв ссылается на raw-ссылки этого репозитория.

**Как открыть:** скачать `Cult2.json` в `Документы/My Games/Tabletop Simulator/Saves/` и загрузить в TTS
(Games → Save & Load).

**Состав:** 10 локаций, 5 планшетов фракций, 25 жетонов, жетон «Экспедиция +3» — все двусторонние тайлы.

**Вторая сторона.** Где её пока нет, оборот — отдельный файл `*_back.jpg` (копия лица). Чтобы подставить
настоящую сторону, замените этот файл в репозитории под тем же именем и перезагрузите картинки в TTS
(Modding → Cache: удалить кэш этого файла) — или вставьте новую ссылку в Custom Tile → Secondary Image.

Картинки собираются скриптом `tools/tts/prep.ps1` проекта Cult2, сейв — `tools/tts/build_save.mjs`.
