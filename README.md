# Cult2 — материалы для Tabletop Simulator

Публичные картинки сценария TTS настольной игры Cult2 (Константин Селезнёв). Сейв ссылается на raw-ссылки этого репозитория.

**Как открыть:** скачать `Cult2.json` в `Документы/My Games/Tabletop Simulator/Saves/` и загрузить в TTS
(Games → Save & Load). При первой загрузке скрипт сам доводит размеры компонентов (несколько секунд после
загрузки картинок) и пишет об этом в чат — после этого игру стоит сохранить.

**Состав:**
- три колоды локаций по рубашкам — красная, жёлтая, зелёная; в каждой 5 карт × 5 копий = 25 карт;
- «Экспедиция» — двусторонний тайл размером с карту;
- жетон +3 / +5 — круглый, двусторонний, 5 штук;
- 5 планшетов фракций (Крыса, Таракан, Ворона, Ящер, Обезьяна) — двусторонние квадраты размером с карту;
- 20 жетонов отрядов (по 4 на фракцию), двусторонние: лицо с иконкой (1, 2, Металл, 4), оборот — простой 4, 2, 3, 1;
- бесконечный мешок жетонов Металла.

**Стол:** пять зон игроков (три снизу, две сверху). В зоне —
10 мест под карты (два ряда по 5, с привязкой), планшет — в первом месте, под ним отряды простой стороной вверх (1…4)
и стартовые 3 Металла; в центре — сетка 3×5 мест под карты, колоды, Экспедиция, жетоны +3/+5, мешок Металла.

Картинки собираются скриптом `tools/tts/prep.ps1` проекта Cult2, сейв — `tools/tts/build_save.mjs`.
